# Wireframe sources

Working files for the "manageLOL Screen Wireframes" design canvas (Draft Board +
Match Day live view), drawn in the game's design system. These are the editable
sources — the published canvas is re-seeded from them, so keep them in sync with
any changes saved in the canvas editor.

Format comparison for the layout work:
- **Format A** — the design canvas built from these files (editable in the browser).
- **Format B** — the sketch wireframes inside `docs/06-ui-architecture.md`.
